**Status:** `[ ] Pendente`

---

## Objetivo

Implementar SEO completo em todas as páginas do site.

---

## Checklist por página

- [ ] `<title>` único e descritivo
- [ ] `<meta name="description">` com até 160 caracteres
- [ ] `<link rel="canonical">` absoluto
- [ ] Open Graph: `og:title`, `og:description`, `og:image`, `og:url`, `og:type`
- [ ] Twitter Card: `twitter:card`, `twitter:title`, `twitter:description`, `twitter:image`
- [ ] `hreflang` para PT e EN
- [ ] Schema.org JSON-LD por tipo de página

---

## Schemas a implementar

| Página | Schema |
|--------|--------|
| Home | `Person`, `WebSite` |
| Projeto | `CreativeWork` |
| Fotografia | `ImageGallery` |
| Pesquisa | `Article` |
| Sobre | `Person` |
| Currículo | `Person` |

---

## Checklist de infraestrutura

- [ ] Criar `src/components/seo/SEO.astro` — componente reutilizável
- [ ] Gerar `public/sitemap.xml` automaticamente
- [ ] Criar `public/robots.txt`
- [ ] Criar `public/rss.xml` (feed de projetos)
- [ ] Configurar `og:image` com fallback global
- [ ] Garantir que rascunhos não apareçam no sitemap

---

## Componente SEO (props)

```ts
interface SEOProps {
  title: string
  description: string
  canonical: string
  ogImage?: string
  ogType?: "website" | "article"
  lang: "pt" | "en"
  schema?: object
  noIndex?: boolean
}
```
