## Objetivo

Configurar o Decap CMS para permitir que o autor crie, edite e publique conteúdo sem editar código.

---

## Checklist

- [ ] Criar `public/admin/index.html`
- [ ] Criar `public/admin/config.yml`
- [ ] Configurar backend GitHub
- [ ] Configurar autenticação OAuth (Netlify ou self-hosted)
- [ ] Criar coleção: **Projetos**
- [ ] Criar coleção: **Fotografia**
- [ ] Criar coleção: **Pesquisa**
- [ ] Criar coleção: **Páginas**
- [ ] Criar coleção: **Configurações do Site**
- [ ] Configurar upload de mídia para `/public/media/`
- [ ] Configurar preview de rascunhos
- [ ] Testar fluxo: Rascunho → Revisão → Publicado

---

## Coleções

### Projetos

Campos obrigatórios: `title`, `subtitle`, `summary`, `slug`, `lang`, `category`, `date`, `cover`, `status`

Campos opcionais: `context`, `problem`, `research`, `references`, `moodboard`, `storyboard`, `process`, `result`, `gallery`, `videos`, `technical_sheet`, `credits`, `bibliography`, `notes`, `tags`, `related_projects`

### Fotografia

Campos: `title`, `slug`, `year`, `description`, `cover`, `gallery`, `technique`, `dimensions`, `location`

### Pesquisa

Campos: `title`, `slug`, `summary`, `date`, `body`, `bibliography`, `tags`

### Configurações

Campos: `site_title`, `site_description`, `og_image`, `social_links`, `contact_email`, `analytics_id`

---

## Fluxo Editorial

```
Rascunho → Revisão → Preview → Correções → Publicado → Indexado
```

Nenhum conteúdo em `status: draft` deve ser publicado no build.
