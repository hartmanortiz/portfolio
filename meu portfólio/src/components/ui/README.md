# Componentes UI — Nível 1

Átomos reutilizáveis. Sem dependências de outros componentes.

## Componentes previstos

| Componente  | Descrição                              | Status      |
|-------------|----------------------------------------|-------------|
| `Button`    | Botão discreto, sem aparência tech     | Etapa 4     |
| `Input`     | Campo de texto para busca/formulário   | Etapa 4     |
| `Badge`     | Etiqueta de categoria/tag              | Etapa 4     |
| `Divider`   | Separador editorial                    | Etapa 4     |
| `Icon`      | Ícone de traço fino                    | Etapa 4     |

## Regras

- Nenhum componente UI pode depender de outro componente UI.
- Todos os estilos devem estar no arquivo `.css` correspondente.
- Cada componente deve ter um `README.md` próprio.
